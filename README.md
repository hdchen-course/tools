# tools

A small collection of personal command-line tools.

## Contents

- **[claude-session-picker](claude-session-picker/)** — a zero-dependency,
  keyboard-driven menu for listing and resuming your [Claude Code](https://claude.com/claude-code)
  sessions from a single terminal. Reads Claude's own session store, shows each
  session's title / project / last-active time with a live marker, and opens the
  one you pick. Runs one session at a time out of the box (hub mode) and upgrades
  to concurrent sessions automatically when `tmux` is installed. See its
  [README](claude-session-picker/README.md) and
  [user manual](claude-session-picker/docs/MANUAL.md).
